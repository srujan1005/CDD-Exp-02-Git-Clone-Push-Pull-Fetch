# CDD Lab Experiment 2: Git Operations - Clone, Push, Pull, Fetch

## Objective
Perform Git operations: clone, push, pull, fetch and repository synchronization.

## Duration
2 Hours

## Tasks
1. Clone an existing repository.
2. Make local changes and commit.
3. Push changes to the remote repository.
4. Pull updates from the remote.
5. Practice `git fetch` and understand the difference from `git pull`.
6. Synchronize local and remote repositories.

## Commands Reference
```bash
git clone <repository-url>
git push origin main
git pull origin main
git fetch origin
git status
git log --oneline --graph --all
```

## Expected Outcome
Successfully synchronized local and remote repositories.
